## APIs

- **0xArchive REST API** — Versioned REST API (/v1) for current and historical market data namespaced by venue family (Hyperliquid core/Spot/HIP-3/HIP-4, Lighter). API key auth via X-API-Key header. (`https://api.0xarchive.io`)
- **0xArchive WebSocket API** — Real-time WebSocket streaming and historical replay. Bearer API key sent during handshake. Documented via prose/schema pages; no AsyncAPI file published. (`wss://api.0xarchive.io/ws`)
- **0xArchive MCP Server** — Hosted, read-only MCP server (streamable-http transport, tools enabled) using client-managed OAuth bearer with scope mcp:market.read. No 0xArchive API key required. (`https://mcp.0xarchive.io/mcp`)
