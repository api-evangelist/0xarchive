# 0xArchive Docs
> 0xArchive is one API for historical and live market data on Hyperliquid and Lighter. Hyperliquid families expose L4 and Lighter exposes L3. Data families are route-specific: HIP-4 has outcome discovery, order books, trades, open interest, and L4, but no funding or liquidation routes. History and freshness are stated by route and market family.
> Lighter funding records are returnable. Retrieve current funding separately for Hyperliquid and Lighter, retaining each source's units and timestamp. Currently served Lighter funding values must not be compared across venues or annualized pending normalization repair.

## API Reference

- [Reference](https://docs.0xarchive.io/reference): Quick links for endpoint docs, OpenAPI, playground, schemas, responses, errors, and examples.
- [REST API](https://docs.0xarchive.io/rest-api.md): Route atlas and OpenAPI reference entry point.
- [Order Book Routes](https://docs.0xarchive.io/rest-api/order-books.md): L2, L3, L4, snapshots, history, and depth-specific route selection.
- Depth rule for agents: use Hyperliquid core or HIP-3 `/orderbook/{symbol}/l2` for full-depth aggregated L2 on covered symbols from March 10, 2026 onward; request levels via `depth`. Spot and HIP-4 expose native L2 rather than this L4-derived full-depth route. Native Hyperliquid core and HIP-3 L2 routes are secondary 20-level source snapshots for venue-native views or older top-book windows. Route, depth, and venue access depend on the exact endpoint and account/key contract; inspect OpenAPI and the response before relying on a route.
